# SQL-портфолио: аналитика сервиса доставки (PostgreSQL)

Набор SQL-запросов на модели сервиса доставки: клиенты, курьеры, товары, заказы.
Данные синтетические, генерируются скриптом, реальных данных в репозитории нет.

## Схема данных
`users`, `couriers`, `products`, `orders` (с массивом `product_ids`),
`user_actions` (действия клиента), `courier_actions` (действия курьера).

## Что внутри
### basic
| Файл | Бизнес-вопрос | Приёмы |
|---|---|---|
| 01 | Среднее число заказов на пользователя | CTE, COUNT DISTINCT, AVG |
| 02 | Товары дороже минимальной цены | подзапрос |
| 03 | Товары дороже средней на 20+ руб. | подзапрос |
| 04 | Активные пользователи за неделю | CTE, интервалы |
| 05 | Неотменённые заказы | NOT EXISTS |
| 06 | Заказы пользователя против среднего | CTE, оконная функция |
| 07 | Цены со скидкой | CASE |
| 08 | Заказы курьеров без записи клиента | NOT EXISTS |

### intermediate
| Файл | Бизнес-вопрос | Приёмы |
|---|---|---|
| 01 | Выручка по дням и рост к предыдущему дню | `UNNEST`, CTE, `LAG` |
| 02 | Доля отмен по полу и возрасту | CTE, `CASE`, `EXISTS`, `FILTER` |
| 03 | Среднее время доставки по дням | CTE, `EXTRACT(EPOCH ...)` |
| 04 | Топ-3 курьера по дням | `ROW_NUMBER` с `PARTITION BY` |
